An agent retrying a 400 error. A loop that never converges. A model swap that triples output tokens. By the time anyone notices, the bill is already written. tokensave blocks the request before the provider is called — and shaves 60–80% off everything that gets through.

npm install tokensave
import TokenSaver from "tokensave";

const client = new TokenSaver({
  apiKey: process.env.OPENAI_API_KEY,
  maxCostPerRequest: 0.50,   // one call, hard limit
  maxCostPerHour:    5,      // loop guard
  maxCostPerDay:     25,     // the number you can sleep on
});

// everything else stays the same

What ceilings give you

Three limits, checked before the call

savedByCeiling is money the ceilings stopped you from spending. For a loop that would have retried until the budget died, that number is the whole point. The test suite asserts the request never reaches the provider — calls === 0.

What ceilings don't cover

And the 60–80% that just leaks

Ceilings stop disasters. These three stop the slow bleed — the money going out on every single call, all day, forever.

Semantic cache

Same question, reworded, answered from cache. Timestamps, UUIDs, emails and long numbers are normalized out before hashing — so "fetch data at 2026-01-15" and "fetch data at 2026-09-20" hit the same entry.

up to −40%

Prompt compression

Strips "please", "kindly", "I would like you to", "in order to". Drops duplicated sentences. Meaning survives; tokens don't.

−10 to −25%

Model routing

"What is Python?" never needed $30/M. Complexity is scored per request; simple ones go to a cheap model in the same family, complex work stays put.

−30 to −60%

Every response carries its own receipt — savedUsd, baselineUsd, costUsd, and the routing reason. You verify the claim yourself. No dashboard, no trust required.

Honest limits

What this does not do

ClaimReality
Catch reworded questionsYes — if the vocabulary matches. Normalization, not embeddings. True paraphrases slip through.
Route perfectlyNo — it's a heuristic on surface features. A short-but-hard question can be routed down. route: false turns it off.
Compress safely alwaysMostly — regex-based, no summarization. Aggressive prompts may lose nuance. Check tokensSaved.
Fix a provider double-chargeNo — that's a billing dispute. Different problem.
Replace your observabilityNo — we measure cost, not quality. Use Langfuse alongside.

Why this exists

Every piece of this already existed as an open-source library. GPTCache for caching. LLMLingua for compression. LiteLLM for routing. Cost-ceiling patterns in a dozen blog posts.

The waste and the risk persisted anyway — because assembling them into something you'd actually run in production took longer than most teams had.

That gap is the product. Not new technology. The distance between "this is possible" and "this is running for me." We closed it to one import.
