LLM cost optimization you can verify yourself

Every cost-optimization tool claims 60–80% savings. Almost none let you check the arithmetic. That is the actual problem with the category.

Three places the money goes

LeakMechanismRecovery
Repeated questionsSame question reworded, billed in fullup to −40%
Filler tokens"please", "I would like you to", duplicated sentences−10 to −25%
Wrong-sized modelgpt-4 answering "what is Python"−30 to −60%

Make the claim falsifiable

The fix is not a better algorithm — it is putting the number where the customer can check it:

{
  model: "gpt-4o-mini",
  costUsd: 0.0000212,      // what you paid
  baselineUsd: 0.00243,    // what you would have paid
  savedUsd: 0.0024088,     // the difference
  route: "routed down: 3 tokens, 1 simple patterns"
}

Now the claim is auditable. If it is wrong, you will see it immediately.

Limits you should assume

  • Normalization-based cache, not embeddings: catches reworded repeats with the same vocabulary, not true paraphrases.
  • Heuristic routing: a short-but-hard question can be routed down. Disable when precision matters.
  • Regex compression: strips filler, does not summarize. Check tokensSaved.

These are documented rather than hidden, because a savings tool you cannot verify is a marketing page with an API.
